# 数据与失败恢复

## 交接包包含什么

交接包是任务状态摘要：目标、带来源的约束、验收标准、已确认决策、失败方案与原因、重要文件引用和下一步。它不是完整聊天备份，也不需要认证文件或密钥。

`csm` 将 checkpoint、操作记录与监测结果保存在自己的本地状态目录。真正执行 `handoff` 时，会启动用户已有的 Codex CLI：初始提示词和新会话读取的项目内容会通过该 Codex 配置使用的模型服务处理。请在运行前核对目标 profile/provider 和材料，不要把“本地存储”理解为模型调用全程离线。

只列出任务必须的文件。不要把 `.env`、密码、token、私钥、认证缓存或与任务无关的个人信息加入 checkpoint。工具会拒绝常见认证、密钥和私有配置路径，但文件名检查不能识别所有敏感内容，仍需检查。测试样例全部是合成内容。

## 不确定性要保留

- 不知道当前 source session ID，就先确认；不能选最新日志或使用 `--last`
- 没有可用上下文数据，就显示 `unknown`；累计 token 不能换算成当前占用率
- 快照覆盖 Git 状态/差异统计及 `important_files` 的内容哈希；不覆盖所有项目文件的完整内容，也不证明没有其他写入者
- 模型返回接收报告，表示已确认材料字段，不是已证明完全理解任务
- 高上下文占用、压缩事件或重复候选只提供检查/交接建议，不证明模型退化

## 写入与权限

旧会话保留，用户的未提交改动保留。交接本身不提交、暂存、回滚代码，也不切换当前 TUI。准备 checkpoint 前停止自己和已知后台任务的写入；变化中的项目不适合生成稳定交接包。

新会话的初始化使用 Codex 只读沙箱，只核对材料。恢复后先检查 `/status` 和 `/permissions`，不要假设目标 profile 自动恢复原来的写权限。`csm` 不替用户放宽沙箱、审批、hook 信任或其他安全设置。

只读沙箱主要约束 Codex 的本地执行；它不是对所有已安装插件、hook 或远端系统的独立安全隔离层。只在可信的现有 Codex 配置中运行。材料中的指令属于待核对的任务数据，不能授权递归交接或初始化期间的项目修改。

## 操作记录与重试

操作从准备到结束记录 operation ID；重复执行时始终复用原 ID，并阅读返回的状态：

| 状态 | 含义与下一步 |
| --- | --- |
| `prepared` | 已保存准备状态，尚未完成启动 |
| `starting` | 已开始启动，新 session 的创建结果尚未完全建立 |
| `initializing` | 已取得新 session ID，正在等待接收报告 |
| `ready` | 初始化回合成功结束、报告通过校验、快照核验通过；可按返回命令恢复 |
| `failed` | 已确认未满足完成条件；检查具体错误与已有 session ID |
| `uncertain` | 无法确认启动或完成结果；先核对，不能直接换 ID 再创建 |

复用 operation ID 会返回已保存的结果，而不会再启动会话。若返回 `reused: true` 和 `snapshot_revalidated: false`，历史 `ready` 仅表示当时通过校验；后续项目改动和新 checkpoint 没有在这次重试中重新验证。先检查变化，再决定如何继续已有新会话。

`thread.started` 不是成功证明。需要同时满足真实新 ID、成功的终止事件、零退出码、有效接收报告和快照核验。

若已有新 session ID，按工具给出的准确恢复方式检查该会话，不要因为初始化失败又创建一个。同一 source session 有带新 ID 的失败初始化时，工具会阻止启动其他 handoff；即使重新生成 checkpoint，也不能绕过这个保护。用 `csm status` 查看已有 ID 和准确恢复命令，在该新会话中完成剩余只读核验。之后若还需要交接，以已恢复的新会话 ID 作为 source。不要删除操作记录来强行重建。若还没有 ID 而创建结果不确定，先使用本机受支持的只读方式核对；工具没有可靠核对入口时，保留记录并人工检查。不要修改 Codex 的会话数据库或伪造记录“修复”状态。

## 常见阻塞

| 情况 | 处理 |
| --- | --- |
| 目标 profile 不存在或无法加载 | 核对准确名称和当前版本的 profile 布局，不回退 |
| 未登录、模型不可用或服务错误 | 在同一 Codex 环境解决问题；不把凭据填入 checkpoint |
| 材料缺项、必读文件丢失 | 修正 checkpoint，再准备新的交接包；已说明依据的预期删除单独记录 |
| 项目在核验时变化 | 停止已知写入、重新核对材料和快照 |
| 超时或进程中断 | 先查看操作记录和新 ID，保留不确定性，避免重复创建 |
| 初始化权限不足 | 确认需要读取的具体路径，不改成危险权限模式 |

技能安装包包含通用说明、模板和代码；运行时生成的任务包位于独立状态目录，不应打入分发包或提交到仓库。安装器拒绝不受管理的同名技能目录及符号链接目录；它不会修改用户的模型、profile 或 Codex 配置。

卸载技能或 CLI 与清除状态数据是分开的。需要删除旧交接记录时，先确认没有仍在使用它们的会话；不要顺手删除 Codex 的原始会话记录。
